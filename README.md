# ABNT_DEX
Propomos o desenvolvimento de uma aplicação web, altamente interativa e com design premium, para servir como o "Orientador TCC ABNT" físico no espaço de trabalho do usuário. Esta ferramenta permitirá simular margens de páginas, gerar citações e referências com base nas regras atualizadas da ABNT e consultar um guia interativo de normas.
